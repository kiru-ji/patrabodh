# Sample Government Documents

This directory contains sample government document images for testing PatraBodh.

## How to Add Samples

1. Take photos of actual government forms (remove personal information first!)
2. Or download official template/sample forms from government websites
3. Save as JPEG/PNG in this directory

## Recommended Test Documents

| Document | Source | Notes |
|----------|--------|-------|
| Aadhaar Enrollment Form | UIDAI website | Bilingual Hindi/English |
| Ration Card Application | State PDS portal | Usually Hindi only |
| PM-KISAN Registration | pmkisan.gov.in | Hindi with English labels |
| Voter ID Form 6 | NVSP portal | Bilingual |
| PAN Form 49A | NSDL/TIN-NSDL | English only |
| Ayushman Bharat Card | PM-JAY portal | Hindi/English |
| Income Certificate | State e-district | Varies by state |
| Birth Certificate | Municipal corporation | Varies by city |

## ⚠️ Privacy Notice

**NEVER include documents with real personal information.** Use:
- Official blank templates
- Redacted/anonymized copies
- Self-created mock documents that look realistic

## Creating Mock Documents

For hackathon demos, create realistic-looking mock documents using:
- Canva or Google Docs with government-style formatting
- Include typical fields, stamps, and headers
- Use placeholder names like "राम कुमार" / "Rajesh Kumar"
